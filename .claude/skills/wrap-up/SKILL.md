# Wrap up

1. Summarize what was done this session in 3-5 bullets.
2. Append a dated entry to `docs/progress.md` with: done, in progress, next steps, open questions.
3. If you learned a durable rule or gotcha, propose a one-line addition to `CLAUDE.md` and ask before editing it.
4. Show the user the entry. Do not commit unless asked.
